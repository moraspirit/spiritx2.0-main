# SpiritX 2.0

**Reinvent the Game.**

Official website of **SpiritX 2.0**, an inter-university sports innovation competition organized by **MoraSpirit, University of Moratuwa, Sri Lanka**.

SpiritX 2.0 brings together university students to explore innovative ideas, develop practical solutions, and rethink the future of sports through technology and creativity.

🌐 **Official Website:** https://spiritx.moraspirit.com

## About This Repository

This repository contains the source code of the official SpiritX 2.0 website.

The project is publicly available to encourage learning, collaboration, and open-source development. Developers are welcome to explore, fork, modify, and reuse the source code under the terms of the MIT License.

## Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Three.js
- Motion
- Cloudflare Turnstile

## Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/moraspirit/spiritx2.0-main.git
cd spiritx2.0-main
```

**2. Install dependencies**

```bash
corepack enable
pnpm install
```

**3. Configure environment variables**

```bash
cp .env.example .env.local
```

Update `.env.local` with the configuration values required for your environment.

**4. Start the development server**

```bash
pnpm dev
```

**5. Build for production**

```bash
pnpm build
```
